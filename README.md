Forecasts GTA VI's launch-day Twitch viewers hour by hour, from the first hour's count and 38 past big launches. A kernel-weighted log-log regression: each hour's viewers are predicted from the hour-1 print, weighting past launches by how close their hour-1 size is. On the four practice launches it scores a mean pinball loss of 0.182 (log scale), against the house baseline's 0.387.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
